Politique de Confidentialité

Dernière mise à jour : Août 2026

Principe fondamental : Traitement 100 % local et souveraineté absolue des données.

1. Absence de serveur tiers

L'application Mon Patrimoine est une application web s'exécutant intégralement dans votre navigateur web (architecture Full Client-Side JavaScript).

Absolument aucune donnée saisie dans l'application, aucun identifiant, ni aucun jeton d'authentification ne transite ni n'est stocké sur un quelconque serveur tiers ou hébergeur intermédiaire.

2. Intégration des services de stockage cloud

Lorsque vous choisissez d'activer la synchronisation via un service de stockage cloud (Dropbox ou Google Drive), les principes suivants s'appliquent quel que soit le service :

  • La connexion s'effectue directement et exclusivement entre votre navigateur et les serveurs sécurisés du service choisi, via le protocole standard OAuth 2.0. Aucune donnée ni identifiant ne transite par un serveur intermédiaire.
  • Vos fichiers de données patrimoniales restent exclusivement dans votre propre espace de stockage personnel ; l'application n'a strictement aucun accès au reste de vos fichiers.
  • Votre adresse email n'est utilisée que pour identifier le compte connecté (reconnexion automatique, affichage dans l'aide) ; elle n'est conservée que localement dans votre navigateur.

Seules les autorisations strictement nécessaires sont demandées ; elles diffèrent selon le service :

  • Dropbox : authentification par redirection avec PKCE (client public, sans secret applicatif) ; autorisations files.content.read, files.content.write et account_info.read, dont la portée est limitée au dossier applicatif dédié (App folder).
  • Google Drive : autorisations drive.file et userinfo.email, dont la portée est limitée aux fichiers que l'application a elle-même créés.

3. Données personnelles et cookies

L'application n'utilise aucun cookie publicitaire, aucun traceur d'audience ni aucun outil de télémétrie. Seul le stockage local de votre navigateur (localStorage) peut être utilisé de manière technique pour conserver vos préférences d'affichage ou vos jetons d'accès locaux afin d'assurer le fonctionnement de l'application.

Mon Patrimoine — Application Client-Side respectueuse de votre vie privée.
